# Design Pattern Strategy

## Descrição
Projeto desenvolvido em Java aplicando o padrão de projeto Strategy, permitindo a definição de diferentes comportamentos que podem ser alterados dinamicamente em tempo de execução.

## Tecnologias
- Java
- Design Patterns

## Conceitos Aplicados
- Padrão Strategy
- Polimorfismo
- Programação orientada a objetos

## Objetivo do Projeto
Aplicar o padrão Strategy para entender a separação de comportamentos e a flexibilidade de código.
